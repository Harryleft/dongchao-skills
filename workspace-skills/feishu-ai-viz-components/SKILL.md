# 飞书 AI 可视化图表组件选型技能

> 根据业务场景选择最合适的飞书 AI 图表组件。适用对象：FDE、数据分析师、业务报表搭建者。

## 触发词
- 图表选型 / 可视化组件 / 这个数据用什么图 / 图表怎么选
- 桑基图 / 矩形树图 / 热力图 / 玫瑰图 / 瀑布图 / 旭日图 / 水波图 / 气泡图 / 仪表图 / 马赛克图

## 组件全景速查

| 图表 | 核心用途 | 典型场景 |
|------|---------|---------|
| 桑基图 | 观察流向和转化流失 | 用户路径、资金流转 |
| 矩形树图 | 看整体里的部分大小 | 类目规模、费用占比 |
| 热力图 | 发现二维组合的高低值 | 库存积压、高峰时段 |
| 玫瑰图 | 醒目比较多个类别 | 渠道对比、月度差异 |
| 瀑布图 | 分析增减变化过程 | 损益拆解、库存变化 |
| 旭日图 | 多层级分类关系 | 类目→品牌→SKU |
| 水波图 | 单一指标完成度 | GMV完成率、预算使用率 |
| 气泡图 | 类别规模差异 | 品牌订单分布 |
| 仪表图 | KPI进度和状态 | 目标达成、预警线 |
| 马赛克图 | 二维分类交集 | 渠道×广告类型消耗 |
| 柱状图 | 最通用的类别对比 | 品类排名、状态分布 |
| 条形图 | 横向排名对比 | 长类别名、数量排名 |

## 各组件详细说明

### 1. 桑基图

| 属性 | 内容 |
|------|------|
| **概念** | 用节点表示对象或阶段，用连线表示从来源到目标的流向；线越宽，数量/金额/流量越大 |
| **用途** | 观察一件事从哪里来、流向哪里、在哪一步变多或流失 |
| **典型场景** | 用户路径和转化流失、资金/库存/工时流转、多步骤链路的去向分布 |
| **典型query** | 基于「流量转化表」，展示「来源渠道」到「落地页」的访问量，数值用「访问次数」求和 |
| **数据结构** | 每行是一条"从A到B，流了多少"的记录，至少包含「来源节点」「目标节点」「数值」。多层路径需拆成相邻两步 |

### 2. 矩形树图

| 属性 | 内容 |
|------|------|
| **概念** | 用矩形表示分类或对象，矩形面积越大代表数值越大 |
| **用途** | 观察整体里各部分的大小关系，以及大类下的细分构成 |
| **典型场景** | 商品类目/品牌/SKU的规模分布、费用/销售额/库存占比、多层级分类下哪些子项贡献最大 |
| **典型query** | 基于「商品主数据表」，展示「商品类目」到「品牌」的SKU分布，数值用「SKU数量」求和 |
| **数据结构** | 每行是一条"某个分类下有多少"的记录，至少包含「分类字段」和「数值字段」。多层级加子分类字段 |

### 3. 热力图

| 属性 | 内容 |
|------|------|
| **概念** | 用颜色深浅表示两个维度交叉后的数值大小；颜色越深数值越高 |
| **用途** | 快速发现二维组合里的高值、低值和异常集中区域 |
| **典型场景** | 各品类在各仓库的库存积压、日期和时段下的访问/订单高峰、地区×商品组合的异常 |
| **典型query** | 基于「商品库存状况表」，展示「商品品类」和「仓库」的库存积压，数值用「库存数量」求和 |
| **数据结构** | 每行是一条"(横轴分类)+(纵轴分类)=数值"的记录，包含「横轴字段」「纵轴字段」「数值字段」 |

### 4. 玫瑰图

| 属性 | 内容 |
|------|------|
| **概念** | 分类放在圆周方向，用扇形半径或面积表示数值；花瓣越长/越大，数值越高 |
| **用途** | 用更醒目的方式比较多个类别的大小差异 |
| **典型场景** | 渠道订单金额/数、月份/季度/地区销售差异、分类数据强弱分布 |
| **子类型** | 基础(单分类) / 分组(并列比较) / 堆叠(看总量+构成) / 分组堆叠(复杂对比) |
| **典型query** | 基于「订单流水表」，展示「订单渠道」的订单金额分布，数值用「订单金额」求和 |
| **数据结构** | 基础：至少「分类字段」+「数值字段」。分组/堆叠再加字段 |

### 5. 瀑布图

| 属性 | 内容 |
|------|------|
| **概念** | 按阶段展示数值如何一步步增减，最后得到总计；看清"从起点到终点每一步的贡献" |
| **用途** | 分析总量背后的增减来源和过程贡献 |
| **典型场景** | 收入→成本→费用→净利润的损益拆解、库存/资金变化、GMV差异因素分析 |
| **子类型** | 基础(竖向) / 水平(横向) / 堆叠(子类堆叠) / 分解(更细归因) |
| **典型query** | 基于「月度经营损益表」，展示「损益科目」对净利润的影响，数值用「金额」求和，标记「总计」行 |
| **数据结构** | 每段颜色是若干条"某个阶段增减多少"的记录，包含「阶段/科目」「增减数值」「是否总计」 |

### 6. 旭日图

| 属性 | 内容 |
|------|------|
| **概念** | 用一圈圈同心环展示层级结构，内层上级外层细分；扇形越大数值越高 |
| **用途** | 观察多层级分类的构成关系和占比大小 |
| **典型场景** | 商品类目→品牌→SKU层级分布、组织/地区/渠道层级贡献、费用/库存多级分类集中情况 |
| **典型query** | 基于「商品主数据表」，展示「商品类目」到「品牌」的SKU分布，数值用「SKU数量」求和 |
| **数据结构** | 每行是"上级分类→下级分类→数值"的记录，至少两个层级字段+一个数值字段 |

### 7. 水波图

| 属性 | 内容 |
|------|------|
| **概念** | 用水位高度展示单一指标的完成度或占比；水位越高越接近目标 |
| **用途** | 突出一个核心进度指标，视觉上比普通数字卡更醒目 |
| **典型场景** | GMV/销售额/利润目标完成率、库存消化率/任务完成率/预算使用率 |
| **子类型** | 圆形(通用) / 菱形(重点指标) / 星形(装饰感，适合活动/里程碑) |
| **典型query** | 基于「每日店铺运营指标」，展示GMV目标完成率，数值用「GMV」求和，手动指定目标值 |
| **数据结构** | 需要当前值字段+目标值字段。当前目标值需手动指定；也可直接用0~1比例值 |

### 8. 气泡图

| 属性 | 内容 |
|------|------|
| **概念** | 用圆形面积表示数值大小；气泡越大数值越高 |
| **用途** | 直观看出不同类别的规模差异，也能表达层级关系 |
| **典型场景** | 品牌/商品/渠道的订单金额分布、各类目下子项规模、多对象数值强弱 |
| **子类型** | 普通气泡(一组类别) / 嵌套气泡(父泡套子泡) / 多根节点嵌套(并排多组层级) |
| **典型query** | 基于「订单流水表」，展示不同「品牌」的订单金额分布，数值用「订单金额」求和 |
| **数据结构** | 普通至少「分类字段」+「数值字段」。嵌套加层级关系字段 |

### 9. 仪表图

| 属性 | 内容 |
|------|------|
| **概念** | 用刻度盘和指针展示单一指标在目标区间里的位置 |
| **用途** | 展示核心KPI的进度和状态，比数字更强调达成程度 |
| **典型场景** | GMV/销售额/利润目标进度、库存周转/预算使用/任务完成率、是否接近预警线 |
| **典型query** | 基于「每日店铺运营指标」，展示GMV完成进度，数值用「GMV」求和，手动指定目标值 |
| **数据结构** | 通常只需要一个当前值字段+目标值/取值范围。当前目标值需手动指定 |

### 10. 马赛克图

| 属性 | 内容 |
|------|------|
| **概念** | 用矩形块展示两个分类交叉后的规模和占比；块越大占比越高 |
| **用途** | 同时看两个分类维度下的构成关系，发现主要贡献组合 |
| **典型场景** | 广告渠道×投放类型的消耗分布、品类×品牌订单金额占比、地区×商品组合 |
| **子类型** | 基础(完整构成) / 简化(弱化标签，类别多时更清爽) |
| **典型query** | 基于「广告投放消耗明细」，展示「投放渠道」和「广告类型」的消耗分布，数值用「消耗金额」求和 |
| **数据结构** | 每行是"(分类A)+(分类B)=数值"的记录，包含两个分类字段+一个数值字段 |

### 11. 柱状图

| 属性 | 内容 |
|------|------|
| **概念** | 用柱子高度比较不同类别的数值大小 |
| **用途** | 最通用的类别对比、排名对比和构成拆解 |
| **典型场景** | 品类商品数量、上下架状态分布、品类/商品/状态的总量和构成差异 |
| **子类型** | 基础/分组/堆叠/百分比堆叠/分组堆叠/分组百分比堆叠 |
| **典型query** | 基于「商品主数据表」，展示不同「商品品类」的商品数量，数值用「商品数量」求和；可按「上下架状态」分组或堆叠 |
| **数据结构** | 基础至少「分类字段」+「数值字段」。分组/堆叠再加系列字段 |

### 12. 条形图

| 属性 | 内容 |
|------|------|
| **概念** | 横向展示的柱状图，用条形长度比较类别数值 |
| **用途** | 类别名较长、类别较多或需要横向排名的对比场景 |
| **典型场景** | 品类商品数量排名、上下架状态分布、各分类下不同状态的占比结构 |
| **子类型** | 基础(简单排名) / 分组(并列比较多组) / 百分比堆叠(只看占比) |
| **典型query** | 基于「商品主数据表」，展示不同「商品品类」的商品数量，数值用「商品数量」求和；可按「上下架状态」分组或百分比堆叠 |
| **数据结构** | 基础至少「分类字段」+「数值字段」。分组或堆叠再加系列字段 |

## 选型决策树

```
需要展示什么？
│
├─ 流向来去方向
│   ├─ 多条路径转化 → 桑基图
│   └─ 单条路径增减过程 → 瀑布图
│
├─ 分类对比
│   ├─ 看整体构成
│   │   ├─ 单层级 → 矩形树图
│   │   └─ 多层级 → 旭日图
│   ├─ 看排名 → 柱状图(竖) / 条形图(横)
│   ├─ 看二维交叉 → 热力图 / 马赛克图
│   └─ 看大小差异
│       ├─ 有层级 → 气泡图(嵌套)
│       └─ 无层级 → 玫瑰图 / 气泡图(普通)
│
├─ 进度/状态
│   ├─ 单指标完成率 → 水波图 / 仪表图
│   └─ KPI仪表盘 → 仪表图
│
└─ 时间趋势
    └─ (一般用折线图，不在本组件范围内)
```

## 按客户行业推荐

| 行业 | 推荐图表 | 说明 |
|------|---------|------|
| 零售/电商 | 桑基图、矩形树图、水波图 | 用户路径、品类分析、GMV完成率 |
| 制造业 | 瀑布图、热力图、柱状图 | 成本拆解、库存矩阵、产量对比 |
| 金融/保险 | 瀑布图、仪表图、旭日图 | 损益分析、KPI监控、资产层级 |
| 广告/营销 | 马赛克图、玫瑰图、条形图 | 渠道×类型消耗、渠道对比、排名 |
| 物流/供应链 | 桑基图、热力图、气泡图 | 货物流转、仓库×品类库存、供应商规模 |

## 通用数据结构模式

所有图表组件遵循同一套数据结构规律：

| 维度数量 | 图表选择 | 数据结构 |
|---------|---------|---------|
| 1分类 + 1数值 | 柱状图/条形图/玫瑰图/气泡图/水波图/仪表图 | 分类字段 + 数值字段 |
| 2分类 + 1数值 | 热力图/马赛克图 | 横轴字段 + 纵轴字段 + 数值字段 |
| 来源+目标+数值 | 桑基图 | 来源节点 + 目标节点 + 数值 |
| 阶段+增减值+总计标记 | 瀑布图 | 阶段/科目 + 增减数值 + 是否总计 |
| 多层级 + 数值 | 矩形树图/旭日图/嵌套气泡图 | 层级1字段 + 层级2字段 + ... + 数值字段 |

## 一、开箱即用型（零配置，面向全员）

### 1. 飞书知识问答

| 属性 | 说明 |
|------|------|
| **核心能力** | 基于企业全域知识（消息、文档、知识库）智能答疑 |
| **技术成熟度** | M3（生产就绪期） |
| **所需前提** | 企业有足够的知识沉淀（文档、知识库等） |
| **使用门槛** | 无需配置，开通即用 |
| **适用场景** | 员工自助问答、培训资料查询、制度文档检索、技术FAQ |
| **不适用场景** | 需要操作业务系统、需要执行多步骤任务 |

**典型客户画像：** 知识密集型企业（高科技、咨询、生物医药、法律）

### 2. 智能会议纪要

| 属性 | 说明 |
|------|------|
| **核心能力** | 会议语音转文字、实时总结、会后回顾、待办提炼 |
| **技术成熟度** | M4（全面应用期） |
| **所需前提** | 飞书 V7.25+，需单独购买 |
| **使用门槛** | 会中一键开启 |
| **适用场景** | 周会/月会、客户会议、评审会、头脑风暴 |
| **不适用场景** | 非会议场景（如单独录音文件需上传妙记） |

**典型客户画像：** 会议频繁的团队（销售、产品、项目管理）

### 3. 飞书 aily（智能伙伴）

| 属性 | 说明 |
|------|------|
| **核心能力** | 对话式问答 + 任务执行 + 智能体定制 + MCP |
| **技术成熟度** | M3（生产就绪期） |
| **所需前提** | 开通aily权限，可选配置企业知识/MCP工具 |
| **使用门槛** | 开箱即用，配置人设/知识/工具可提升效果 |
| **适用场景** | 全员通用AI助手、数据分析、PDF问答、文档生成、代码编写 |
| **可增强配置** | 接入企业知识库、连接业务系统MCP、自定义技能 |
| **不适用场景** | 需要搭建独立业务系统 |

**典型客户画像：** 全员适用；尤其适合需要AI辅助日常办公的团队

## 二、系统搭建型（低/零代码，面向业务人员）

### 4. 多维表格 AI

| 属性 | 说明 |
|------|------|
| **核心能力** | AI字段捷径、AI公式生成、工作流自动化、仪表盘 |
| **技术成熟度** | M3（生产就绪期） |
| **所需前提** | 开通多维表格AI能力 |
| **使用门槛** | 有基础表格操作能力即可 |
| **适用场景** | 数据分析与洞察、库存管理、项目管理、客户跟进、自动化报表 |
| **性能指标** | 支持1000万+行数据，计算响应毫秒级 |
| **不适用场景** | 需要复杂审批流、多系统集成、定制UI |

**典型客户画像：** 运营、销售、项目管理团队

### 5. 飞书妙搭

| 属性 | 说明 |
|------|------|
| **核心能力** | 对话式建系统、自动生成应用、AI Coding |
| **技术成熟度** | GA（正式发布） |
| **所需前提** | 开通妙搭权限 |
| **使用门槛** | 自然语言描述需求即可，无需代码 |
| **适用场景** | 内部申请审批工具 | ✅ 适合 |
| | 简单资产登记系统 | ✅ 适合 |
| | 员工活动报名工具 | ✅ 适合 |
| | 部门数据看板入口 | ✅ 适合 |
| | 门店管理工具 | ✅ 适合 |
| | 客户关系管理系统 | ✅ 适合 |
| | ERP/财务管理 | ❌ 不适合（太重） |
| | 复杂多系统集成 | ❌ 不适合 |
| **支持形式** | 网页应用、机器人、小组件 |

**典型客户画像：** 有快速搭建轻量系统需求的业务部门

## 三、平台集成型（aPaaS，面向开发者）

### 6. 飞书低代码平台（aPaaS）— AI 组件

| AI组件 | 能力 | 适用场景 |
|--------|------|---------|
| **AI 助手** | 对话式分析应用数据、编排自定义技能 | 让用户通过对话查询/分析业务数据 |
| **AI 按钮** | 智能洞察、信息总结、智能问答 | 在页面中嵌入一键AI分析能力 |
| **AI 数据请求** | 图片理解、文本理解 | 自动识别图片/文档中的信息并录入系统 |
| **AI 审批** | AI预审、AI判断、智能审批规则 | 自动审批流，规则可配置 |
| **智能信息录入** | 辅助数据录入 | 减少人工录入工作量和错误 |
| **AI 数据处理** | 数据清洗、转换 | 业务流程中的数据预处理 |
| **AI 生成工作流** | 自动生成流程 | 自然语言描述需求即可生成自动化流程 |
| **数据模型AI助手** | 辅助创建数据模型 | 通过对话加速系统建模 |

**适用场景：** 需要搭建完整的、复杂的业务系统（如：HRM全模块、CRM、项目管理平台）
**不适用场景：** 简单的一次性工具（用妙搭更快）

### 7. 智能伙伴创建平台

| 属性 | 说明 |
|------|------|
| **核心能力** | 创建自定义AI伙伴，配置人设、知识、技能、工具 |
| **适用场景** | 客服机器人、HR助手、IT支持机器人、行业顾问 |
| **技术门槛** | 中等，需配置prompt和工具 |
| **关联产品** | 可发布到飞书、服务台、客服系统 |

## 四、选型决策树

### 快速分类：按需求类型

```
客户需求
│
├─ 需要AI回答问题？
│   ├─ 基于企业知识 → 知识问答
│   └─ 需要联网+执行任务 → aily
│
├─ 需要AI处理会议？
│   └─ 会议录音/实时转文字 → 智能会议纪要
│
├─ 需要搭建系统？
│   ├─ 轻量工具（审批/报名/看板）→ 妙搭
│   ├─ 数据驱动（分析/库存/跟进）→ 多维表格AI
│   └─ 复杂业务系统（HRM/CRM）→ aPaaS（含AI组件）
│
└─ 需要专属AI Agent？
    ├─ 通用办公 → aily（配置知识+工具）
    └─ 特定岗位/行业 → 智能伙伴创建平台
```

### 按客户行业推荐

| 行业 | 推荐AI组件组合 | 说明 |
|------|---------------|------|
| 制造业 | 多维表格AI + aPaaS AI组件 | 生产数据管理、设备巡检、工单系统 |
| 零售/营销 | 妙搭 + 多维表格AI + aily | 门店管理、活动报名、数据看板 |
| 金融/咨询 | 知识问答 + 智能纪要 + aPaaS | 知识管理、会议纪要、客户管理 |
| 互联网/科技 | aily + 妙搭 | 全员AI助手 + 快速原型搭建 |
| 教育/培训 | 知识问答 + 多维表格AI | 培训资料问答、学员数据管理 |
| 医疗/医药 | aPaaS + 知识问答 | 患者管理、药品知识库 |

## 五、FDE实战要点

### 三方对齐会中如何推荐AI组件

1. **先挖痛点，再推组件** — 不要一上来就推销某个AI工具
2. **用"可以/不可以"对比表** — 每推一个组件的同时说清楚它做不到什么
3. **组合优先** — 大多数场景需要2-3个组件组合使用
4. **从轻到重** — 先从开箱即用的推，再升级到系统搭建

### Token消耗预估参考

| 组件 | 预估消耗（月/100人） | 说明 |
|------|--------------------|------|
| 知识问答 | 低-中 | 取决于提问频率 |
| aily | 中-高 | 重度使用较高 |
| 多维表格AI | 低-中 | 按自动化频次 |
| 妙搭 | 中 | 按系统活跃度 |
| aPaaS AI组件 | 中-高 | 按流程执行次数 |
